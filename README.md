# HotelMapService
just a simple map website for a hotel agency
## How to build
1. Install Node.JS
2. Clone git repo: ' git clone https://github.com/SaB131X/HotelMapService '
3. Install dependencies: ' npm install '
4. Run debug or build script: ' npm run dev ' (to debug project on localhost) or ' npm run build ' (to get files for website server)
5. Use files from ' dist ' folder on a website server (just drop them in)
